CSS만으로 그리는 등각 2.5D 데이터 컴포넌트

WebGL도 캔버스도 없이, 블록의 면 세 개를 2D matrix() 하나씩으로 그립니다. 크롬북처럼 GPU가 약한 기기에서도 가볍게 돌고, 값이 바뀔 때가 아니면 CPU를 쓰지 않습니다.

앱별 메모리 사용량 MB · 예시 데이터

이렇게 만듭니다

  • 2D 변환만. preserve-3d, 캔버스, 렌더 루프를 쓰지 않습니다.
  • 색 하나로 세 면. 옆면 음영은 color-mix(in oklch)로 만들어, --iso-c 하나만 바꾸면 블록 전체가 바뀝니다.
  • 텍스트는 DOM. 값과 이름은 일반 텍스트라 선택·복사·번역·스크린 리더가 그대로 동작합니다. 모든 값을 담은 숨김 표도 함께 만듭니다.
  • 테마와 동작 줄이기. 다크 모드(prefers-color-scheme, data-theme)와 prefers-reduced-motion을 토큰 단계에서 따릅니다.

설치

아직 공개된 패키지가 없습니다. npm 패키지 이름은 정해지지 않았고(TBD), 아래 이름과 CDN 주소는 자리 표시용입니다. 지금은 저장소를 받아 소스에서 바로 불러 쓰세요.

<!-- 소스에서 바로 (지금 쓸 수 있는 방법) -->
<link rel="stylesheet" href="/packages/core/src/css/index.css">
<script type="module" src="/packages/core/src/index.ts"></script>

<!-- 공개 뒤 (자리 표시: 이름·주소 미정) -->
npm install <패키지-이름-미정>
<link rel="stylesheet" href="https://cdn.example/<패키지-이름-미정>/iso.min.css">
<script type="module" src="https://cdn.example/<패키지-이름-미정>/iso.min.js"></script>

구성 요소

  • CSS 프리미티브JS 없이 블록·바닥판·라벨을 직접 배치
  • <iso-bars>한 줄 막대
  • <iso-stack>기둥 안에 계열을 쌓는 적층 막대
  • <iso-heatmap>행×열 격자, 셀 높이로 값
  • <iso-ledger>장부처럼 쌓은 기록, 한 장을 앞으로
  • <iso-kpi>지표 하나를 채움 높이로
  • 플레이그라운드JSON과 속성을 바꿔 가며 바로 확인

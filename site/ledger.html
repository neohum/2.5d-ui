Web Component

<iso-ledger>

기록을 장부처럼 한 장씩 쌓습니다. selected 속성으로 고른 한 장을 앞으로 빼내어 보여 줍니다. 버전 기록, 결재 이력처럼 순서가 있는 기록에 씁니다.

예시

릴리스 기록, 세 번째 장 선택 (예시 데이터)

속성

속성형식의미
dataJSON기록 배열. 잘못된 JSON이면 그리지 않고 console.error 후 오류 문구를 보인다
selected정수(인덱스)앞으로 빼낼 장
unit숫자(px)--iso-u 값. 기본 24
max, height-units숫자공통 속성(축척 최댓값, 최대 블록 높이)
label문자열접근성 캡션(aria-label과 숨김 표 caption)

data 항목

키형식의미
k문자열 · 필수장 이름(예: 버전)
note문자열 · 선택설명

이벤트

장을 누르거나 Enter·Space를 누르면 iso-select(detail: { index, item })가 버블링됩니다. 고른 장을 앞으로 빼려면 받은 인덱스를 selected에 다시 넣으세요.

const ledger = document.querySelector("iso-ledger");
ledger.addEventListener("iso-select", (e) => {
  ledger.setAttribute("selected", e.detail.index);
});

접근성

  • 장마다 포커스를 받고, 숨김 표가 모든 장의 이름과 설명을 담습니다.
  • 선택은 위치(앞으로 빠짐)로 보입니다. 고른 장의 내용은 화면의 글로도 함께 보여 주세요 — 버전 기록 뷰어가 그 예입니다.

Web Component

<iso-kpi>

지표 하나를 블록의 채움 높이로 보여 줍니다. data 대신 value, max, label, suffix 속성을 씁니다.

예시 데이터

속성

속성형식의미
value숫자지표 값. 0 이상
max숫자꽉 찬 높이에 해당하는 값
label문자열지표 이름이자 접근성 캡션
suffix문자열값 뒤에 붙는 단위(예: %, 대)
unit숫자(px)--iso-u 값. 기본 24
height-units숫자꽉 찬 높이. 기본 5

이벤트

블록을 누르거나 Enter·Space를 누르면 공통 규격대로 iso-select가 버블링됩니다. 지표 상세 화면으로 넘어가는 데 쓰세요.

document.querySelector("iso-kpi").addEventListener("iso-select", () => {
  location.href = "/battery";
});

접근성

  • label을 꼭 지정하세요. 값·단위와 함께 블록의 접근 가능한 이름이 됩니다.
  • 채움 높이만으로는 정확한 값을 읽기 어려우므로 값 라벨이 함께 보입니다.
